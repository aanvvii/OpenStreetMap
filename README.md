# OpenStreetMap Explorer 🌍

A web-based interactive map application that helps users explore nearby essential services and find useful places around a selected location.

## ✨ Features

- **Interactive Map:** Explore locations using an interactive map interface.
- **Location Search:** Search for a place by entering its name.
- **Nearby Services:** Find nearby pharmacies, hospitals, ATMs, fuel stations, public toilets, and drinking water facilities.
- **Near Me:** Use browser geolocation to search around your current location.
- **Distance Filter:** Search within a selected radius of 500 m, 1 km, 2 km, or 5 km.
- **Map Styles:** Switch between street, light, and satellite views.
- **Save Places:** Save useful locations for later access.
- **Search Filters:** Filter results by name, accessibility, and opening hours.
- **Directions:** Open directions to a selected location.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Leaflet.js
- OpenStreetMap data
- Overpass API
- Nominatim and Photon geocoding services
- Esri map tiles

## 🚀 How to Run

1. Clone or download this repository.
2. Open `openstreetvibrant_map.html` in a web browser.
3. Enter a location in the search bar.
4. Select a service category and search radius.
5. Explore the results on the map and save useful places.

An internet connection is required to load map tiles and retrieve location data.

## 📌 Project Purpose

This project demonstrates how web mapping, geolocation, external APIs, and interactive JavaScript components can be combined to create a location-based service discovery application.
